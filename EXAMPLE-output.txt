EXAMPLE — what Willow says during a real session
================================================

Lightly cleaned from an actual end-to-end run: a watcher in one window, files
being changed and tests being run in another. Each "Willow:" line is what Willow
spoke aloud (and showed as text).

  Willow: starting up, taking a first look at the project...
  Willow: watching my-app. I'll tell you what the agent changes. Press Enter
          any time to hear the current state. Type help to hear what you can
          ask me.

  Willow: 2 files: created src/café-menü.tsx (1 lines); created src/login.js (3 lines).
          - created src/café-menü.tsx (1 lines)
          - created src/login.js (3 lines)

          ^ the spoken form is one sentence, but the text prints one file per
            line so a screen reader can be arrowed through it. And a filename in
            any language arrives exactly as written.

  Willow: edited src/login.js (+2 -1 lines).

  Willow: quietly undid the change to src/login.js.

          ^ the agent changed the file and changed it straight back. Nothing to
            see in the final state; easy to miss; worth hearing.

  Willow: renamed src/login.js to src/auth.js.

          ^ not "created auth.js; deleted login.js" — the content hashes match,
            so this is a rename with certainty, not a guess.

  Willow: created test_thing.py (5 lines).

  Willow: then 'python -m pytest test_thing.py -q' FAILED (exit code 1).
          1 failed, 1 passed in 0.09s. First failure: test_thing.py::test_bad.

          ^ the exit code is real. The summary and the failing test name are
            quoted verbatim from pytest's own output — evidence of the same kind
            as the exit code, and the difference between a notification and an
            answer.

  [developer typed "recap"]
  Willow: session recap, 1 minute in: 4 files touched, 6 chunks of work,
          1 build or test run, 1 of them failing.

  [developer pressed Enter]
  Willow: state right now: 3 new files since we started.

  Willow: stopped watching. Goodbye.


Other things Willow says, from the same rulebook
------------------------------------------------

  Willow: the agent has changed login.js in 3 attempts that each ended with
          'npm test' failing.

          ^ counted, not inferred. Willow does not claim the agent is stuck ON
            that file — it can't know that. It reports what it counted.

  Willow: Claude says: Claude needs permission to run npm install.

          ^ from a Claude Code hook. Missing that prompt means the agent sits
            idle and you have no way to tell.

  Willow: I couldn't run 'npm test' — the command 'npm' wasn't found on this
          computer. That's not a test failure; it just didn't run.

          ^ an unknown never becomes a verdict. This is the case that used to be
            announced as "npm test FAILED, exit code 127".

  Willow: the agent ran 'npm run build' (I couldn't check whether it passed).

          ^ when a hook reports a command but carries no exit code.


See README.md to run it yourself, and RULES.md for exactly how Willow decides
what to say.
